技能加点与连招

推荐加点顺序 主Q
R
终极技能
法术涌动：法术强度提升，法力值消耗降低。
Q
主要伤害技能
超时空能量：向目标区域发射法术，造成魔法伤害并减速。
W
核心控制
曲光屏障：创造一道屏障，阻挡敌方飞行道具，并反弹伤害。
E
机动性技能
过载：下一次普攻变为法术伤害，并在范围内留下残影。
经典连招公式 必学

对线消耗：W(挡) -> Q(消耗) -> E(普攻)

爆发连招：R(强化) -> Q -> E -> W(护盾) -> Q(二段)

追击/逃生：E(残影) -> Q -> W(护盾) -> E(再次位移)

注意：瑞兹的技能在叠加法术强度时收益极高，务必在团战中寻找机会开启大招叠加层数。

实战技巧与克制关系

克制关系
  • 克制： 没有硬控的法师、射手、短手近战（如安妮、阿狸）。
  • 被克制： 带有强硬突进（如劫、亚索）和强力控制（如泰坦、锤石）的英雄。
注意事项
  • 瑞兹非常依赖蓝量，注意补刀并利用草丛回复蓝量。
  • 大招层数叠加后不要轻易交出，这是你团战输出的核心。
  • 利用W技能可以挡住敌方关键指向性技能（如安妮晕、卡萨丁大招）。
